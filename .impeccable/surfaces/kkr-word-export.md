# Preview dan unduhan Word KKR — K-18

Mode: Operate. Ordinary extension of the confirmed Hearth/Jakarta/compact UI.
Authority: the agreed K-18 selected-version Word output contract. Source review
does not establish applicant acceptance or a live PSE status change.

Routes /kkr/{document}/versi/{version}/preview and
/kkr/{document}/versi/{version}/word identify the selected version explicitly.
The saved form adds template, purpose and work steps. Preview and DOCX share
KkrPrint narratives and eight cell strings: No., Kode, Uraian, Spesifikasi,
Satuan, Harga, Pengusul and Catatan Hasil Reviu. Notes, responses, decisions and
newer submitted-version context retain their original review-version meaning.

Viewing and downloading have separate policies; document/version mismatch is
rejected. Non-final preview explains that subsequent supervision decisions may
change its supervision section. Final preview and download read the retained
model and DOCX bytes from one private version archive. Missing or corrupt
archives fail closed and are not silently regenerated or overwritten.

The shared workspace preserves the dark sidebar, warm canvas, bright panels,
terracotta actions, Jakarta typography and compact spacing. KKR heading actions
wrap within the scoped workspace. The preview uses existing panels, fact lists,
status messages and pre-wrapped narrative. Its eight-column table has a row/version
caption and a labelled focusable scroll region; its 1100px minimum width stays
inside that region. All these are source observations, not measured screenshots.

DOCX A4 geometry, eight-column proportions, Calibri typography, repeating table
header and PAGE footer belong to the document output. The preview explicitly
delegates page breaks to Word. These document choices do not change UI tokens.
DESIGN.md and design.json remain the incumbent K-3 record; no visual-world
replacement or global token change was made in this extension.

Evidence: KkrController, KkrPrint, KkrWord, KkrExport, K-18 migration, KKR Blade,
scoped/shared CSS and KkrWordTest source. The K-18 checkpoint passed 159 PHP tests / 2016 assertions; the later combined
K-18/K-19 run passed 170 PHP tests / 2168 assertions. The design review is source-only.
Actual Word desktop pagination/render QA was stopped by the developer and
remains pending; authenticated desktop/mobile UI, keyboard validation and
applicant UAT also remain unverified. The source example documents were not
opened or copied during documentation; no artifact was generated or rendered.
